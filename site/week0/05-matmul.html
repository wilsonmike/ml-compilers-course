Matrix multiply is a pile of dot products

Matrix multiply is the one operation neural networks spend most of their time in, and in week 3 you write it yourself. This page shows what it computes, starting from a table of test scores. You need no linear algebra. It is multiplying and adding.

Goal

Multiply two grids of numbers by hand and with three loops, and say which shapes can be multiplied.

Warm up

Two questions from lesson 0.4, from memory. Pulling an idea back out of your head is what makes it stay.

A grid with 3 columns is stored row after row in a flat buffer. Which position holds row 2, column 1?

r*cols + c with r = 2, cols = 3 and c = 1.

2*3 + 1 = 7. Two whole rows are 6 boxes, then one step along.

A (2, 3) grid is stored as 1 2 3 4 5 6. A loop reads positions 1 and 4. What did it walk?

The positions are 3 apart, and one row is 3 boxes long.

Each step skips one whole row, so the column stays put: 0*3 + 1 and 1*3 + 1. It read 2 and 5, which is column 1. Matrix multiply walks columns this way.

Three students, two tests

A teacher gives two tests, each marked out of 10. Test 1 is a short quiz. Test 2 is the final, so it should count for more. Here are the scores:

studenttest 1test 2
Ana86
Ben59

The teacher gives each test a weight: a number that says how much one point on that test is worth. Test 1 has weight 2 and test 2 has weight 3. A student's total is their test 1 score times 2, plus their test 2 score times 3.

What is Ana's total?

Her test 1 score is 8 and its weight is 2. Her test 2 score is 6 and its weight is 3.

8*2 + 6*3 = 16 + 18 = 34.

You just did this whole lesson in small. You multiplied numbers that belong together, then added the products. Matrix multiply is that same move, done once for every student and every way of weighting. A neural network does it with millions of numbers. Its scores are the numbers coming in, and its weights are what it learned in training.

A dot product: multiply matching pairs and add

The move has a name. Lesson 0.4 called a row of numbers a vector. The dot product of two vectors of the same length is one number: multiply the matching pairs, then add the products. It is written with a dot. Here are Ben's scores and the weights:

[5, 9] · [2, 3] = 5*2 + 9*3 = 37
  1. Pair them up. First with first, second with second: 5 with 2, and 9 with 3.
  2. Multiply each pair. 5*2 = 10 and 9*3 = 27.
  3. Add the products. 10 + 27 = 37.

The two vectors must have the same length. If they did not, some number would have no partner.

[1, 0, 2] · [3, 5, 4] = ?

Three pairs, so three products. Then add them.

1*3 + 0*5 + 2*4 = 3 + 0 + 8 = 11.

Complete: a dot product

dot takes two vectors of the same length and returns their dot product. The loop and the running total are written. One line still adds 0 on every turn. Make it add the product of the matching pair.

A matrix times a vector: one dot product per row

Now do all three students at once. The scores are a matrix of shape (3, 2): 3 rows of 2. The weights are a vector of 2 numbers. A matrix times a vector does one dot product for each row of the matrix, so the answer has one number per row:

scores      weights    totals
[ 8  6]                [34]
[ 5  9]  @  [2  3]  =  [37]
[10  7]                [ ?]

The @ sign means this kind of multiply. It is the symbol Python uses for it.

What is the missing total?

Dot the last row, [10, 7], with the weights [2, 3].

10*2 + 7*3 = 20 + 21 = 41. The weights were used three times, once for each row.

In memory the matrix is flat, row after row: 8 6 5 9 10 7. Lesson 0.4 found row r, column c at position r*cols + c. So a program needs two loops:

  1. Loop over the rows. For each row r, start a total at 0.
  2. Walk the row. For each column c, multiply the matrix number at r*cols + c by vector number c, and add the product to the total.
  3. Keep the total. It is number r of the answer.

A matrix times a vector

Write matvec. It takes a matrix m stored flat, row after row, its number of rows and columns, and a vector v with one number per column. It returns one total per row. The scores 8 6 5 9 10 7 with 3 rows, 2 columns and the weights 2 3 give 34 37 41.

What is Ben's total under plan 1?

Ben's row of scores is [5, 9]. The plan 1 column of weights, read downward, is [4, 1].

5*4 + 9*1 = 20 + 9 = 29. Ben beats Ana under plan 0 and loses to her under plan 1.

That table of totals is a matrix multiply, written C = A @ B. Rows and columns count from 0, and C[i][j] means the cell of C at row i, column j. The whole rule is one sentence: C[i][j] is row i of A dotted with column j of B.

Step through a second one. Here A has 2 rows of 3 and B has 3 rows of 2. Week 3 uses these same two matrices.

Which shapes can be multiplied

Not every pair of matrices can be multiplied. Predict the rule before you read it.

The scores have shape (3, 2): 3 students and 2 tests. The teacher writes five grading plans. Which shape must the weights have for scores @ weights to work?

Each plan is one column of weights. How many weights does one plan need?

A plan needs one weight per test, so each column holds 2 numbers. That is 2 rows and 5 columns: (2, 5). The answer has shape (3, 5), one total for each student under each plan.

A row of A has as many numbers as A has columns. A column of B has as many numbers as B has rows. A dot product needs two vectors of the same length, so those two sizes must be equal.

(M, K) @ (K, N)  gives  (M, N)
  1. Write the shapes side by side. (3, 2) @ (2, 5).
  2. Check the inner sizes. The two in the middle are 2 and 2. They match, so the multiply works.
  3. Keep the outer sizes. The answer is (3, 5). The inner size is gone, because each dot product added it away.

The order matters. (2, 5) @ (3, 2) does not work, because its inner sizes are 5 and 3.

Three loops

A program fills C one cell at a time. One loop picks the row i, one picks the column j, and the innermost loop does the dot product for that cell. All three matrices are flat, so every read uses r*cols + c. Here A has shape (rows, mid) and B has shape (mid, cols).

def matmul(a, b, rows, mid, cols):
    c = [0] * (rows * cols)
    for i in range(rows):
        for j in range(cols):
            total = 0
            for k in range(mid):
                total = total + a[i * mid + k] * b[k * cols + j]
            c[i * cols + j] = total
    return c
let matmul a b rows mid cols =
  let c = Array.make (rows * cols) 0 in
  for i = 0 to rows - 1 do
    for j = 0 to cols - 1 do
      let total = ref 0 in
      for k = 0 to mid - 1 do
        total := !total + a.(i * mid + k) * b.(k * cols + j)
      done;
      c.(i * cols + j) <- !total
    done
  done;
  c
  1. Pick a cell. The i and j loops visit every cell of C.
  2. Start its total at 0. Each cell is its own dot product.
  3. Walk a row and a column. As k counts up, i*mid + k steps along row i of A. k*cols + j steps down column j of B, jumping one whole row each turn.
  4. Store the total. It goes in row i, column j of C.

The innermost line does one multiply and one add. It runs rows * cols * mid times.

How many times does the innermost line run for (2, 3) @ (3, 4)?

The answer has shape (2, 4). How many cells is that, and how many pairs does each cell multiply?

2 * 4 = 8 cells, and each is a dot product of 3 pairs: 8 * 3 = 24.

The triple loop in C, its strides and its FLOP count, for when week 7 makes it fast

In C, with all three matrices stored row-major as flat arrays (lesson 0.4):

void matmul(int M, int N, int K, const float *A, const float *B, float *C) {
  for (int i = 0; i < M; i++)
    for (int j = 0; j < N; j++) {
      float acc = 0.0f;                   // 0.0f is a float literal; acc is the running sum
      for (int k = 0; k < K; k++)
        acc += A[i*K + k] * B[k*N + j];   // A walks a row, B walks a column
      C[i*N + j] = acc;
    }
}

It does M * N * K multiplies and the same number of adds. Look at the index into B: as k goes up it jumps N floats at a time, a stride of N, so it's cache-unfriendly for large N. Reordering the loops, tiling them and keeping values in registers is how later weeks make this fast. The math doesn't change, only the order.

Count it

A 256 by 256 matmul is 256 * 256 * 256 = 16,777,216 multiply-adds. People quote it as about 33.5 million FLOPs (floating point operations), because each multiply-add is 2. That FLOP count is how you'll grade your own speed later: FLOPs divided by seconds.

A matrix multiply with no loops, from reshape and reduce: week 5 builds this

This way of writing a matrix multiply now belongs to week 5. Lesson 5.4 teaches it step by step, with the real ops. What follows is a preview and the background for the last C drill below.

The dot product is a multiply followed by a reduce (sum). In the course's IR that pattern turns into two operations: a broadcast multiply and a reduce. The course syllabus writes a 256 by 256 matrix multiply (a "GEMM") with no loops at all:

%0 = buffer 65536 dtype=f32 slot=0
%1 = buffer 65536 dtype=f32 slot=1
%2 = reshape %0 [256 256 1]
%3 = reshape %1 [256 1 256]
%4 = mul %2 %3
%5 = reduce %4 op=add pop=1

This is the syllabus's shorthand. The course's own .uir spells it out a little more: it loads each buffer before reshaping it, and it broadcasts with an explicit expand. The idea is broadcasting, which week 5 teaches. Reshape both buffers to 3 axes, with a size-1 axis in a different place in each. Then mul broadcasts each to the full (K, M, N) cube of products, and reduce sums away the leading axis k (pop=1 means it sums away 1 leading axis). That's the multiply-then-sum of the dot product, done for every (i, j) at once.

Here %4 has shape [256 256 256]: each size-1 axis broadcasts to match the other side. That's a cube of 16.7 million products, which the reduce collapses to [256 256]. A good compiler never actually stores that cube. It fuses the multiply into the sum (week 4).

Below is the same thing with K = 2, M = 2, N = 3, so you can see every number.

Read the axes carefully

Because the summed axis comes first, slot 0 holds A transposed (K by M). Broadcast-multiply, then reduce, is a matmul.

A strided dot product

Write dot(a, sa, b, sb, n): the sum of a[i*sa] * b[i*sb] for i from 0 to n-1. With a stride, the same function can dot a row (stride 1) with a column (stride = row width) of a flat matrix, which is exactly what one cell of a matmul does.

Count the FLOPs

Write gemm_flops(M, N, K): the FLOP count of an (M, K) @ (K, N) matmul, counting a multiply-add as 2.

Learn Python · Lesson 1

First steps in Python

Python is the language you will write your compiler in. In this lesson you write your first lines of it, right here on the page. You do not need to install anything yet.

Goal

Write short Python programs that use numbers, text and names, and read the message Python gives you when a line is wrong.

Where this goes

There are six short Learn Python lessons, P.1 to P.6. In step 1 the page ran your three-line programs for you. After these six lessons you go back and write the program that ran them. If you already write Python every day, go there now.

Run one line

In step 1 you wrote lines like %a = add %x 3. In Python the same sum is x + 3. The box below holds a small Python program. It has two lines:

def add_three(x):
    return x
  1. Line 1 names it. The program is called add_three. The x in parentheses is its input, a number handed in each time it runs.
  2. Line 2 gives the answer. Whatever comes after the word return is handed back.

A named program with an input is called a function. We say this function returns x. Right now that is the input, unchanged.

Your first line of Python

Change line 2 so the function returns x + 3. Keep the four spaces at the start of the line. Then press Run. The page runs your function with a few inputs and checks each answer, as it did in step 1. When the examples pass, press Submit to run the rest of the tests.

You just wrote Python. P.2 teaches you to write a function from an empty page. Until then, every exercise gives you line 1 and you write the rest.

Warm up

Two questions from step 1, from memory. Pulling an idea back out of your head is what makes it stay.

What is %out?

Work out the first line, then use its answer twice in the second.

%a is 3, and 3 × 3 is 9.

The page ran each of your programs several times. What changed from one run to the next?

Think about the long param line.

The program stayed the same and the input changed. Your Python function works the same way: x is different on each run.

Python keeps two more habits from step 1. Lines run from top to bottom, and a name has to be made before a line can use it.

Show a value with print

A Python program is lines of text. Python reads them from the top, one at a time, and does what each line says. One instruction you will use all the time is print, which shows a value on the screen.

This program has three lines. How many numbers does it show on the screen?

print(1 + 1)
4 + 4
print(3)

Only one word in this program puts anything on the screen.

It shows 2 and then 3. Python works out 4 + 4, gets 8 and throws it away, because nobody asked to see it.

print is a function that comes with Python. To use a function, write its name and then parentheses. What you put in the parentheses is its input. Python works the input out first, so print(1 + 1) shows 2.

On this page, a program is followed by what it shows:

print(2 + 3)
print(10)
5
10

Computers do exactly what the text says, never what you meant. If you want to see a value, you have to say so with print.

Try any line yourself

Every exercise box runs real Python. Type a print(...) line at the bottom of a box, with no spaces in front of it, and press Run. What it shows appears under "Your output".

Values and types

Text goes between quotes. Guess what Python does with it before you read on.

The first line shows 14. What does the second line show?

print(7 + 7)
print("7" + "7")

The quotes make "7" a piece of text, not a number.

"7" is text that holds the character 7. Between two pieces of text, + joins them end to end, so you get 77.

Everything a program works with is a value. Every value has a type, which says what kind of value it is and what you can do with it. Four types cover this lesson:

typewhat it holdsexamples
inta whole number, any size, positive or negative7, -12, 0

boola boolean: yes or noTrue, False

7 and "7" look alike but have different types. You can make a value of another type with three functions: int("42") is the number 42, str(42) is the string "42" and float(2) is 2.0.

Text into a number

double("21") should return the number 42. Press Run first and look at what it returns now. Then fix line 2. int(text) gives the number that the string spells.

More about types: asking for a type, None, and floats that are slightly off

type() tells you a value's type. This program shows all five built-in types you will meet in this lesson and the next:

print(type(7))
print(type(3.5))
print(type("7"))
print(type(True))
print(type(None))
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>

None is a real value that means "no value here". Its type is NoneType. You'll meet it again in P.2.

int(3.9) is 3. It cuts off the fraction and does not round.

Floats are stored in binary, and most decimal fractions can't be written exactly in binary, so they are close approximations. print(0.1 + 0.2) shows 0.30000000000000004. That is not a bug in Python. Every language that uses standard floats does the same. Ints are always exact.

Names point at values

In step 1 every line gave its value a name, like %a. Python does this with =. A name can also be given a new value later. Guess what that does to a second name.

What does this program show?

price = 3
count = price
price = 5
print(count)

What value does price have at the moment line 2 runs?

It shows 3. Line 2 gives count the value price has right then. Line 3 changes only price.

A variable is a name that points at a value. = means "make this name point at this value". It does not mean "is equal to". Step through the program to see each arrow:

count = price does not tie the two names together. It points count at the value price points at right now.

That is why this line, which looks impossible as math, is fine when score points at 10:

score = score + 1
  1. Work out the right side. score points at 10, so score + 1 is 11.
  2. Move the name. score now points at 11.

Use a name twice

In step 1 you wrote a program for (x + 3) × (x + 3). Here it is in Python, almost. Line 2 points the name a at the sum. Line 3 returns a alone. Change line 3 so it returns a times a. In Python, * means multiply.

Rules for names, and why the arrows matter later

Names can use letters, digits and _, can't start with a digit, and are case sensitive: Score and score are different names. Pick names that say what the value means, like total_price, not x2.

For a number, "the name points at a value" and "the name holds a value" behave the same, because you can't change a number in place. In P.3 you'll meet lists, which can change in place, and then the arrows explain a bug that confuses almost everyone once.

Arithmetic

You have used + and *. Division has a surprise.

What does print(6 / 2) show?

One of the four types in the table is for numbers with a fractional part.

/ always gives a float, even when the answer is whole. So it shows 3.0, not 3.

A symbol like + or / is called an operator. These are the ones for numbers:

operatorwhat it doesexample
+ - *add, subtract, multiply7 * 2 is 14
/divide, always giving a float7 / 2 is 3.5
//floor division: how many whole times one number fits in another7 // 2 is 3
%modulo: what is left over after floor division7 % 2 is 1
**raise to a power2 ** 10 is 1024

When a line has several operators, Python uses the order from school math. Parentheses go first, then powers, then * / // %, then + -. So 2 + 3 * 4 is 14, and (2 + 3) * 4 is 20. When in doubt, add parentheses. They cost nothing and make your meaning plain.

Celsius to Fahrenheit

celsius_to_f(c) should return the temperature in Fahrenheit: multiply by 9, divide by 5, then add 32. celsius_to_f(100) is 212.0. The starter forgets one step. On line 1, the : float and -> float parts are notes about types. Python ignores them, and you can too for now.

Check the order of operations, and try -40, which is the same in both scales.

The full order of operators, for when an answer surprises you

This order is called precedence. Higher rows go first. Within one row, Python works left to right, except **, which goes right to left.

first to lastoperatorsexample
1parentheses ( )(2 + 3) * 4 is 20
2**2 ** 3 ** 2 is 2 ** 9, which is 512
3a minus sign in front, -x-2 ** 2 is -(2 ** 2), which is -4
4* / // %2 + 3 * 4 is 14
5+ -10 - 4 - 3 is (10 - 4) - 3, which is 3

-2 ** 2 is -4, because the power happens before the minus sign. (-2) ** 2 is 4. Nobody remembers every row of the table, which is one more reason to add parentheses.

A handy use of %: n % 2 is 0 exactly when n is even. With negative numbers, // and % behave in a way that surprises people who know C. Lesson 0.7 covers that, and you won't need it until then.

Strings

A string is text between quotes. Each character in it has a position, and you read one character by putting its position in square brackets after the string.

What does this program show?

word = "python"
print(word[1])

Python does not start counting at 1.

Counting starts at 0, so word[0] is p and word[1] is y. A 6-letter word has positions 0 to 5.

A character's position is called its index. Three more tools cover most of what you do with strings:

  • + joins two strings end to end. This is called concatenation.
  • len() counts the characters in a string, spaces included.
  • An f-string builds text out of values. Put an f before the opening quote. Anything inside { } is worked out and dropped into the text.
name = "Ada"
age = 36
print(len(name))
print(name[0])
print(f"{name} is {age + 1} next year")
3
A
Ada is 37 next year

Initials

initials(first, last) should return the first letter of each name, with a dot after each one. initials("Ada", "Lovelace") is 'A.L.'. Keep the letters as they come: initials("grace", "hopper") is 'g.h.'.

Index 0 of each name, and an f-string to put them together.

More string tools: quotes inside a string, repeating, counting from the end

Single and double quotes mean the same thing. Use whichever lets you put the other kind inside: "it's" and 'say "hi"' are both fine.

* repeats a string: "ab" * 3 is 'ababab'. The empty string "" has length 0.

Negative indexes count from the end, so word[-1] is the last character, 'n'. An index past the end is an error: word[6] stops the program with IndexError: string index out of range.

Strings can't be changed in place. word[0] = "P" is an error too. To get a different string, you build a new one.

After a colon inside the braces of an f-string you can say how to format the value. f"{2 / 3:.2f}" is '0.67', because :.2f means "a float with 2 digits after the point".

Read an error message

Every programmer sees errors all day. They are not a sign that you are doing badly. They are Python telling you what went wrong and where. Here is a program saved in a file called shop.py:

price = 4
count = 3
total = price * cuont
print(total)

Running it shows this:

Traceback (most recent call last):
  File "C:\Users\you\shop.py", line 3, in <module>
    total = price * cuont
                    ^^^^^
NameError: name 'cuont' is not defined. Did you mean: 'count'?

Read only the last line of the message. What went wrong?

Which name is inside the quotes on the last line?

"Not defined" means no line has made that name. It is a typo for count, and Python even guesses that.

This whole block is called a traceback. Read it from the bottom up:

  1. The last line first. It names the kind of error, NameError, and says what happened.
  2. Then the lines above. They say where: file shop.py, line 3, with the line itself printed and the bad part marked by ^^^^^.
  3. Fix one thing and run again. The program stopped at the error, so line 4 never ran.

An exercise box shows you the last line of the message, after the word "got". That line is enough for the next one.

Fix it from the message

total(price, count) should return the price times the count. Press Run before you change anything, and read the error. Then find the name Python does not know and fix it.

When the types do not match

The error that needs the most thought is a TypeError. It means a line used a value of the wrong type. Here it is in a file called age.py:

age = "36"
print("Next year you are " + age + 1)
Traceback (most recent call last):
  File "C:\Users\you\age.py", line 2, in <module>
    print("Next year you are " + age + 1)
          ~~~~~~~~~~~~~~~~~~~~~~~~~~~^~~
TypeError: can only concatenate str (not "int") to str

The ^ points at the second +. Its left side is a string. Its right side is the int 1. Python will not guess whether you meant the text "361" or the number 37.

You want the sentence to end in 37. Which fix works?

Turn age into a number before you add 1. Then check that nothing still joins a string to a number.

int(age) + 1 is the number 37, and the f-string drops it into the text. The first option ends in 361. The third still joins a string to an int, so it is a TypeError again.

Change one thing, then run again

When something breaks, it's tempting to change three things at once. Then if it works, you don't know which change fixed it, and if it doesn't, you've added two new problems. Read the last line, form one guess, change one thing, run. It feels slow, but it is the fastest way.

Four errors you will meet in your first week, and how a SyntaxError differs

The last line is all you need to read to recognize each one:

the last line starts withwhat caused itthe usual fix
NameError: name 'cuont' is not defineda name that nothing points at: a typo, or a variable used before the line that sets itcheck the spelling and the order of your lines
TypeError: can only concatenate str (not "int") to str"2" + 2: adding a number to a stringconvert one side, with str(2) or int("2")

ZeroDivisionError: division by zerodividing by a value that is 0find out why it is 0, and check for it before you divide

A SyntaxError is different from the others. Python checks the whole file before running any of it, so a syntax error means nothing ran, not even line 1. The output has no "Traceback" line:

print("hello"
print("bye")
  File "C:\Users\you\syn.py", line 1
    print("hello"
         ^
SyntaxError: '(' was never closed

The first line of a traceback, "most recent call last", only matters once you have functions calling functions, in P.2. Python 3.10 doesn't draw the ^^^ marks, and newer versions add color, but the last line reads the same.

Put it together: a clock

A stopwatch counts 125 seconds, and you want to show it as 2:05. Floor division and modulo split a number into big units and small ones:

  1. Count the whole minutes. 125 // 60 is 2.
  2. Find what is left. 125 % 60 is 5.
  3. Pad to two digits. Inside the braces of an f-string, :02 after a value means "at least 2 characters wide, filled with zeros". So f"{5:02}" is 05.
seconds = 125
minutes = seconds // 60
left = seconds % 60
print(f"{minutes}:{left:02}")
2:05

The last exercise adds hours. This time more than one line is yours to write. You can use as many lines as you like before return, each starting with four spaces.

Seconds to a clock

seconds_to_hms(seconds) should return a string like a clock shows it: hours, then minutes and seconds with two digits each. seconds_to_hms(3723) is '1:02:03' and seconds_to_hms(59) is '0:00:59'. Hours are never padded.

An hour is 3600 seconds. // for the whole units, % for what's left, and :02 in an f-string for the padding.

Install Python on Windows, macOS or Linux

You need Python 3.10 or newer. Check whether you already have it. On Windows, type python --version. On macOS and Linux, type python3 --version (the plain python name is often missing or old there). You should see something like Python 3.12.7.

If it's missing, or older than 3.10, install it:

  • Windows: winget install Python.Python.3.12, then close the terminal and open a new one. Or use the installer from python.org, and tick "Add python.exe to PATH" on its first screen. PATH is the list of folders a terminal searches for commands. Without that tick, the terminal can't find python.
  • macOS: brew install python if you use Homebrew, or the installer from python.org.
  • Ubuntu or WSL: sudo apt install python3.

Then check the version again in a new terminal. A terminal reads PATH once, when it opens, so an old window won't see the new install.

On this page, and the ones after it, python means python3 if you are on macOS or Linux.

Two ways to run Python: one line at a time, or a whole file

Python is itself a program, called an interpreter: it reads your text and does what each line says. Type python on its own and press Enter. You'll see a version line and then >>>. That is the prompt of the REPL, short for read, evaluate, print, loop. It reads one line, works it out, prints the result, and waits for the next line. It is the best place to try things.

>>> 2 + 3
5
>>> print("hello")
hello
>>> "hello"
'hello'

The lines that start with >>> are what you type. The lines without it are what Python answers. Notice the last two. print("hello") writes the text hello. Typing "hello" alone makes the REPL show you the value, written the way you'd type it in code, quotes and all. That showing is called the echo, and only the REPL does it. The REPL shows nothing at all when the result is None.

To leave the REPL, type exit() and press Enter.

The second way is a file, as in step 5 above. A file has no echo. If hello.py had a third line that said only 2 + 3, Python would work it out, get 5, and throw it away. In a file, if you want to see something, you print it.

Check yourself

What does 17 // 5 give?

How many whole times does 5 fit into 17?

5, 10, 15 fit. 20 is too big.

5 fits into 17 three whole times, so 17 // 5 is 3. The 2 left over is 17 % 5.

What does 17 % 5 give?

% is the part left over after the whole fives are taken out.

Three fives make 15. What is 17 minus 15?

17 is 3 fives plus 2, so the remainder is 2. That's the same split as 125 seconds into 2 minutes and 5 seconds.

What does 2 + 3 * 2 ** 2 give?

Which goes first: the power, the * or the +?

2 ** 2 first, then the *, then the +.

2 ** 2 is 4, 3 * 4 is 12, and 2 + 12 is 14. Left to right would give 100, which is why the order matters.

What is the type of 8 / 4?

The answer is a whole number. Does that matter for /?

Look back at what print(6 / 2) showed.

/ always gives a float, so 8 / 4 is 2.0. Use // when you want an int.

After these three lines, what is b? a = 4, then b = a, then a = 9.

What does b point at right after b = a runs?

Does moving a to a new value move b too?

b = a points b at the value a has at that moment, 4. Pointing a at 9 afterwards doesn't touch b.

What is len("hello world")?

Count every character, including the one between the words.

5 letters, 1 space, 5 letters: 11. A space is a character like any other.

A traceback ends with TypeError: can only concatenate str (not "int") to str. Which line could have caused it?

The message says a str was being joined to something that wasn't a str.

Which option has a string on one side of + and an int on the other?

"item " + 2 tries to join a string and an int. Write "item " + str(2) or f"item {2}" instead.

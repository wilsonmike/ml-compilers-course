First steps in Python

This lesson starts from nothing. By the end you will have Python installed, a file that runs, and a clear picture of what values, names and errors are. Take it slowly and type every example yourself. Typing is how the ideas stick.

Where this track goes

The six Learn Python lessons are numbered P.1 to P.6, and they lead into week 0. Week 0 ends with lesson 0.7, which is where the course's own Python starts. If you already write Python every day, skip ahead to week 0.

What a program is

A program is a text file of instructions. Python is itself a program, called an interpreter: it reads your whole file, then runs it from the top, one line at a time, doing what each line says. When it reaches the end of the file, it stops.

Here is a complete Python program. It is two lines long.

print("Hello!")
print(2 + 3)

Python reads the first line and writes Hello! on the screen. It reads the second, works out 2 + 3, and writes 5. print is a function, a named piece of work you can ask for. The thing in the parentheses is what you hand it. Nothing else happens, because there are no more lines.

Computers do exactly what the text says, never what you meant. That is frustrating at first, and it is also what makes them reliable. Most of programming is learning to say precisely what you mean.

A terminal and three commands

A terminal is a window where you type commands instead of clicking. You'll use it to run your programs. Open one now:

  • Windows: press the Start key, type Terminal (on Windows 10, type PowerShell), and press Enter. It opens PowerShell.
  • macOS: press Cmd and Space, type Terminal, and press Enter.
  • Linux: on Ubuntu, press Ctrl, Alt and T together.

A terminal is always "in" one folder, called the current folder. When you run a file by name, the terminal looks for it there. Three commands cover almost everything you need, and they are spelled the same on all three systems:

Install Python and an editor

You need Python 3.10 or newer. Check whether you already have it. On Windows, type python --version. On macOS and Linux, type python3 --version (the plain python name is often missing or old there). You should see something like Python 3.12.7.

If it's missing, or older than 3.10, install it:

  • Windows: winget install Python.Python.3.12, then close the terminal and open a new one. Or use the installer from python.org, and tick "Add python.exe to PATH" on its first screen. PATH is the list of folders a terminal searches for commands. Without that tick, the terminal can't find python.
  • macOS: brew install python if you use Homebrew, or the installer from python.org.
  • Ubuntu or WSL: sudo apt install python3.

Then check the version again in a new terminal. A terminal reads PATH once, when it opens, so an old window won't see the new install.

Windows opens the Microsoft Store

On a fresh Windows, typing python may open the Store instead of running anything. That is a placeholder, not Python. Install with winget or python.org as above, then open a new terminal.

For writing code, use VS Code (from code.visualstudio.com) with its Python extension (click the Extensions icon on the left, search for Python, install the one from Microsoft). Open your folder with File, Open Folder, and pick learn-python. VS Code has its own terminal inside it: View, Terminal. It starts in the folder you opened, which saves a lot of cd.

On this page, and the ones after it, python means python3 if you are on macOS or Linux.

Two ways to run Python

Type python on its own and press Enter. You'll see a version line and then >>>. That is the prompt of the REPL, short for read, evaluate, print, loop. It reads one line, works it out, prints the result, and waits for the next line. It is the best place to try things.

>>> 2 + 3
5
>>> print("hello")
hello
>>> "hello"
'hello'

In these sessions, the lines that start with >>> are what you type. The lines without it are what Python answers. Notice the last two. print("hello") writes the text hello. Typing "hello" alone makes the REPL show you the value, written the way you'd type it in code, quotes and all. That showing is called the echo, and only the REPL does it.

To leave the REPL, type exit() and press Enter.

The second way is a file. In VS Code, make a new file called hello.py in your folder, type this, and save it with Ctrl+S (Cmd+S on a Mac):

print("Hello!")
print(2 + 3)
"not shown"
2 + 3

Run it from the terminal, in the folder where you saved it:

python hello.py
Hello!
5

The last two lines of the file printed nothing. A file has no echo. Python works out 2 + 3, gets 5, and throws it away, because nobody asked to see it. In a file, if you want to see something, you print it. VS Code's Run button (the triangle at the top right) does the same as typing python hello.py.

Save before you run

Python runs what is on disk, not what is on your screen. If your change seems to do nothing, check the tab title in VS Code. A dot instead of an X means the file isn't saved yet.

Values and their types

Everything a program works with is a value: a number, a piece of text, true or false. Every value has a type, which says what kind of value it is and what you can do with it. type() tells you a value's type.

>>> type(7)
<class 'int'>
>>> type(3.5)
<class 'float'>
>>> type("7")
<class 'str'>
>>> type(True)
<class 'bool'>
>>> type(None)
<class 'NoneType'>
typewhat it holdsexamples
inta whole number, any size, positive or negative7, -12, 0
floata number with a fractional part3.5, -0.25, 2.0

boola boolean: yes or noTrue, False
NoneType"no value here"None

7 and "7" look alike but are different types. One is a number you can add. The other is a piece of text that happens to contain the character 7. You can convert between them with int(), float() and str():

>>> int("42")
42
>>> str(42)
'42'
>>> float(2)
2.0
>>> int(3.9)
3

int(3.9) cuts off the fraction instead of rounding. And None is a real value that means "nothing". The REPL shows nothing at all when the result is None, which can be confusing. You'll meet it again in lesson 2.

Floats are stored in binary, and most decimal fractions can't be written exactly in binary, so they are close approximations:

>>> 0.1 + 0.2
0.30000000000000004

That is not a bug in Python. Every language that uses standard floats does the same. Ints, on the other hand, are always exact.

Names point at values

A variable is a name that points at a value. You make one with =, which in Python means "make this name point at this value". It does not mean "is equal to".

>>> price = 3
>>> count = price
>>> price = 5
>>> count
3
>>> price
5

Many beginners expect count to be 5 at the end. Step through what each line does:

count = price makes count point at whatever price points at right now, the value 3. It does not tie the two names together forever. Moving price later leaves count where it was.

The right-hand side of = is always worked out first, and then the name is pointed at the result. That's why this line, which looks impossible as math, is fine:

>>> score = 10
>>> score = score + 1
>>> score
11

Python reads score + 1 using the old value, 10, gets 11, and points score at 11. Names can use letters, digits and _, can't start with a digit, and are case sensitive: Score and score are different names. Pick names that say what the value means, like total_price, not x2.

Why the arrows matter later

For a number, "the name points at a value" and "the name holds a value" behave the same, because you can't change a number in place. In lesson 3 you'll meet lists, which can change in place, and then the arrows explain a bug that confuses almost everyone once.

Arithmetic

Python does arithmetic the way you'd expect, with a few symbols to learn:

>>> 7 + 2
9
>>> 7 - 2
5
>>> 7 * 2
14
>>> 7 / 2
3.5
>>> 6 / 2
3.0
>>> 7 // 2
3
>>> 7 % 2
1
>>> 2 ** 10
1024

* multiplies and ** raises to a power. There are two kinds of division. / always gives a float, even when the answer is whole: 6 / 2 is 3.0, not 3. // is floor division: it gives the whole number of times one number fits in another. %, called modulo, gives what is left over.

Together, // and % split a quantity into big units and small ones. 125 seconds is 2 whole minutes and 5 seconds left:

>>> 125 // 60
2
>>> 125 % 60
5

A handy use of %: n % 2 is 0 exactly when n is even. With negative numbers, // and % behave in a way that surprises people who know C. Lesson 0.7 covers that, and you won't need it until then.

When an expression has several operators, Python follows an order called precedence, the same as school math. Higher rows go first. Within one row, Python works left to right, except **, which goes right to left.

first to lastoperatorsexample
1brackets ( )(2 + 3) * 4 is 20
2**2 ** 3 ** 2 is 2 ** 9, which is 512
3a minus sign in front, -x-2 ** 2 is -(2 ** 2), which is -4
4* / // %2 + 3 * 4 is 14
5+ -10 - 4 - 3 is (10 - 4) - 3, which is 3
When in doubt, add brackets

-2 ** 2 is -4, because the power happens before the minus sign. (-2) ** 2 is 4. Nobody remembers every row of the table. Parentheses cost nothing and make your meaning plain to the reader too.

Celsius to Fahrenheit

Write celsius_to_f(c), which returns the temperature in Fahrenheit: multiply by 9, divide by 5, then add 32. celsius_to_f(100) is 212.0. The starter gives you the first line, which starts with def and names the function and its input c. The : float and -> float parts are notes about types that you can ignore for now. The word return hands the answer back. Lesson 2 explains all of these properly.

Check the order of operations, and try -40, which is the same in both scales.

Strings

A string is text between quotes. Single and double quotes mean the same thing. Use whichever lets you put the other kind inside:

>>> "it's"
"it's"
>>> 'say "hi"'
'say "hi"'

+ joins two strings end to end, which is called concatenation. * repeats a string. len() counts its characters, spaces included.

>>> "ab" + "cd"
'abcd'
>>> "ab" * 3
'ababab'
>>> len("hello")
5
>>> len("")
0

Each character has a position, called its index, and you read one with square brackets. Counting starts at 0, not 1. So in a 6-letter word, the indexes are 0 to 5. Negative indexes count from the end: -1 is the last character.

>>> word = "python"
>>> word[0]
'p'
>>> word[5]
'n'
>>> word[-1]
'n'
>>> word[6]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: string index out of range

word[6] asks for a seventh character that isn't there, and Python stops with an error. You'll learn to read those messages at the end of this lesson. Strings also can't be changed in place: word[0] = "P" is an error too. To get a different string, you build a new one.

An f-string is the clearest way to build text out of values. Put an f before the opening quote, and anything inside { } is worked out and dropped into the text:

>>> name = "Ada"
>>> age = 36
>>> f"{name} is {age}"
'Ada is 36'
>>> f"next year: {age + 1}"
'next year: 37'
>>> f"{7:02}"
'07'
>>> f"{2 / 3:.2f}"
'0.67'

After a colon inside the braces you can say how to format the value. :02 means "at least 2 characters wide, padded with zeros", which is how clocks show minutes. :.2f means "a float with 2 digits after the point".

Initials

Write initials(first, last), which returns the first letter of each name, with a dot after each one. initials("Ada", "Lovelace") is 'A.L.'. Keep the letters as they come: initials("grace", "hopper") is 'g.h.'.

Reading your first errors

Every programmer sees errors all day. They are not a sign that you are doing badly. They are Python telling you, quite precisely, what went wrong. Here is a small file, shop.py, with a typo on line 3:

price = 4
count = 3
total = price * cuont
print(total)

Running it with python shop.py prints this:

Traceback (most recent call last):
  File "C:\Users\you\shop.py", line 3, in <module>
    total = price * cuont
                    ^^^^^
NameError: name 'cuont' is not defined. Did you mean: 'count'?

This whole block is called a traceback. Read it from the bottom up:

  1. The last line first. It names the kind of error, NameError, and says what happened: Python met the name cuont, and nothing points at it. Here it even guesses what you meant.
  2. Then the lines above. They say where: file shop.py, line 3, with the line itself printed and the bad part underlined by ^^^^^.

The traceback is printed when the error happens, and the program stops there. Line 4 never ran. The first line of the traceback, "most recent call last", only matters once you have functions calling functions, in lesson 2. Python 3.10 doesn't draw the ^^^ marks, and newer versions add color, but the last line reads the same.

Four errors account for most of a beginner's first week. The last line is all you need to read to recognize each one:

the last line starts withwhat caused itthe usual fix
NameError: name 'cuont' is not defineda name that nothing points at: a typo, or a variable used before the line that sets itcheck the spelling and the order of your lines
TypeError: can only concatenate str (not "int") to str"2" + 2: adding a number to a stringconvert one side, with str(2) or int("2")
SyntaxError: '(' was never closedthe text isn't valid Python at all, here a missing )look at the line it shows and the line before it
ZeroDivisionError: division by zerodividing by a value that is 0find out why it is 0, and check for it before you divide

The TypeError is the one that needs the most thought. Here it is in a file called age.py:

age = "36"
print("next year you are " + age + 1)
Traceback (most recent call last):
  File "C:\Users\you\age.py", line 2, in <module>
    print("next year you are " + age + 1)
          ~~~~~~~~~~~~~~~~~~~~~~~~~~~^~~
TypeError: can only concatenate str (not "int") to str

The marks point at the second +. Its left side is a string (the text plus "36"), its right side is the int 1, and Python refuses to guess whether you meant text "361" or the number 37. The fix depends on what you meant. Here it is int(age) + 1 inside the parentheses, or better, an f-string: f"next year you are {int(age) + 1}".

A SyntaxError is different from the others. Python checks the whole file before running any of it, so a syntax error means nothing ran, not even line 1. The output has no "Traceback" line:

print("hello"
print("bye")
  File "C:\Users\you\syn.py", line 1
    print("hello"
         ^
SyntaxError: '(' was never closed
Change one thing, then run again

When something breaks, it's tempting to change three things at once. Then if it works, you don't know which change fixed it, and if it doesn't, you've added two new problems. Read the last line, form one guess, change one thing, run. It feels slow, but it is the fastest way.

Seconds to a clock

Write seconds_to_hms(seconds), which returns a string like a clock shows it: hours, then minutes and seconds with two digits each. seconds_to_hms(3723) is '1:02:03' and seconds_to_hms(59) is '0:00:59'. Hours are never padded.

An hour is 3600 seconds. // for the whole units, % for what's left, and :02 in an f-string for the padding.

What you can do now

  • Name the type of a value, and convert between int, float and str.
  • Explain what = does to a name, and predict what count is after price moves.
  • Use /, //, % and **, and wrap an expression in parentheses to make its order clear.
  • Index a string, join strings, and build text with an f-string.
  • Read a traceback from the last line up, and fix a NameError, TypeError, SyntaxError or ZeroDivisionError.

Check yourself

What does 17 // 5 give?

How many whole times does 5 fit into 17?

5, 10, 15 fit. 20 is too big.

5 fits into 17 three whole times, so 17 // 5 is 3. The 2 left over is 17 % 5.

What does 17 % 5 give?

% is the part left over after the whole fives are taken out.

Three fives make 15. What is 17 minus 15?

17 is 3 fives plus 2, so the remainder is 2. That's the same split as 125 seconds into 2 minutes and 5 seconds.

What does 2 + 3 * 2 ** 2 give?

Which operator in the precedence table goes first?

2 ** 2 first, then the *, then the +.

2 ** 2 is 4, 3 * 4 is 12, and 2 + 12 is 14. Left to right would give 100, which is why the order matters.

What is the type of 8 / 4?

The answer is a whole number. Does that matter for /?

Look at what the REPL printed for 6 / 2.

/ always gives a float, so 8 / 4 is 2.0. Use // when you want an int.

After these three lines, what is b? a = 4, then b = a, then a = 9.

What does b point at right after b = a runs?

Does moving a to a new value move b too?

b = a points b at the value a has at that moment, 4. Pointing a at 9 afterwards doesn't touch b.

What is len("hello world")?

Count every character, including the one between the words.

5 letters, 1 space, 5 letters: 11. A space is a character like any other.

A traceback ends with TypeError: can only concatenate str (not "int") to str. Which line could have caused it?

The message says a str was being joined to something that wasn't a str.

Which option has a string on one side of + and an int on the other?

"item " + 2 tries to join a string and an int. Write "item " + str(2) or f"item {2}" instead.
